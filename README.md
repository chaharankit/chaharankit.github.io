# Ankit Chahar Portfolio (React V2)

Single-page portfolio built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Scripts

- `npm run dev` starts local development server.
- `npm run build` creates production build in `dist/`.
- `npm run preview` previews the production build locally.
- `npm run lint` runs ESLint checks.

## Contact Form Setup

1. Copy `.env.example` to `.env`.
2. Add your Web3Forms key:
   - `VITE_WEB3FORMS_ACCESS_KEY=your_key_here`
3. Restart dev server after env changes.

## Deployment

GitHub Pages workflow is defined in `.github/workflows/deploy.yml` and triggers on pushes to `react-redesign`.
